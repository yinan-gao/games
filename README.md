# games

## 🐍 贪吃蛇

一个用原生 HTML、CSS 和 JavaScript 编写的贪吃蛇小游戏，不依赖任何第三方库，也不需要构建。

### 开始游戏

用浏览器直接打开 [`snake/index.html`](snake/index.html) 即可（双击文件就行）。

### 操作

| 操作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 移动 | 方向键或 `W` `A` `S` `D` | 在棋盘上滑动，或点按棋盘下方的方向按钮 |
| 开始 / 暂停 / 继续 | `空格` 或 `回车`；`P` / `Esc` 也可以暂停或继续 | 点按“开始游戏”“暂停”“继续”按钮 |

### 规则

- 吃到红色的食物，蛇身变长并得 1 分，移动速度也会逐渐加快。
- 撞到墙壁或自己的身体，游戏结束；蛇占满整个棋盘即为通关。
- 最高分保存在浏览器本地（`localStorage`）中。
- 切换到其他标签页或窗口时会自动暂停。

### 代码结构

| 文件 | 说明 |
| --- | --- |
| `snake/index.html` | 页面结构 |
| `snake/style.css` | 页面样式 |
| `snake/snake.js` | 游戏核心逻辑（移动、转向、碰撞、计分），与界面无关 |
| `snake/main.js` | Canvas 绘制、键盘 / 触屏输入和游戏循环 |
| `snake/snake.test.js` | 核心逻辑的单元测试 |

### 运行测试

需要 Node.js 18 或更高版本，无需安装任何依赖。在仓库根目录运行：

```bash
node --test
```
